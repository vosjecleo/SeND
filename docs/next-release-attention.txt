8. Local-storage encryption

Desktop Matrix and search databases use SQLCipher. Android keeps its existing
SQLCipher store. Private native drafts, scheduled sends, favourites, proxy files
and avatar caches use authenticated encryption; larger buffers run in an isolate.
PWA Matrix records use WebCrypto with opaque lookup keys. PWA search uses the
checksum-pinned SQLite3MultipleCiphers WASM asset in a worker. Existing sessions
and history migrate without a plaintext fallback or missing-key reset. Browser
unlock is automatic, as requested, and its browser-profile/site-code limits are
shown in Local storage alongside quota and persistence controls.
