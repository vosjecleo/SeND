HOW TO APPLY
SHORTEN: replace with the text under AFTER. This also covers plain-English rewrites.
REMOVE: remove the prose block and its unused spacing, not the feature, control or validation.
KEEP: leave the existing text unchanged.
Read Implementation notes before applying a change with conditions or nested strings.
Final text in the CSV is UI copy only: unchanged text for KEEP, proposed text for SHORTEN,
and blank for REMOVE. Reviewer instructions are in separate columns.
These are text values, not escaped Dart/Kotlin/JavaScript source literals.

BOUNDARIES
Existing 1–3-word UI labels are unchanged. Longer labels are edited only where useful.
Do not remove screen-reader labels, dynamic counts, validation, error handling or controls.
Do not rewrite executable source, structured log fields, Open Graph keys or licence notices.
Non-UI resources and platform/web metadata are identified separately in Review scope.
The supplied catalog is the basis for this review; the running app and source tree were not inspected.
Keep existing conditional visibility and safety checks; verify any platform-gating notes in code.
Duplicate literals must stay consistent. A nested literal is not a second independent UI block.

SUMMARY OF THE ACTUAL PROSE
207 entries are classified as UI prose: 156 rewrites, 43 removals and 8 already-brief messages kept.
Other rewrites affect 12 dynamic displays/tooltips and 6 longer labels.
The 8 unchanged prose entries are existing short confirmations, validation messages, file limits
and the instruction to save a recovery key—not retained explanatory paragraphs.
